# 📊 Indices Catalog

A modern, high-performance web application to explore major financial and market index providers and the indices they offer worldwide (e.g., S&P Dow Jones, MSCI, FTSE Russell, Nasdaq, STOXX, Bloomberg, and more).

🌐 **Live Demo:** [https://vivekgautham.github.io/indices](https://vivekgautham.github.io/indices)

---

## ✨ Features

- **🔍 Smart Search & Filtering:** Instant search across index providers, benchmark names, ticker symbols, asset classes, and regional coverage.
- **🏢 Major Index Providers:** Profiles covering index methodology, coverage universe, asset classes, and family offerings.
- **📈 Index Benchmarks:** Detailed metrics, constituents breakdown, weighting methodologies, and asset classification.
- **⚡ Fast & Resilient:** Powered by Vite, React 18, TanStack React Query, and Material UI dark theme.

---

- **Framework:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)

- **Data Fetching & State:** [TanStack React Query](https://tanstack.com/query/latest), [Axios](https://axios-http.com/)
- **Routing:** [React Router v7](https://reactrouter.com/)
- **Code Quality:** [ESLint](https://eslint.org/), [Prettier](https://prettier.io/), [Husky](https://typicode.github.io/husky/), [Lint-Staged](https://github.com/lint-staged/lint-staged), [Commitlint](https://commitlint.js.org/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `yarn` / `pnpm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vivekgautham/indices.git
   cd indices
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.
